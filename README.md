# Does Mandatory Training Improve Worker Outcomes?

A causal evaluation of a firm-wide soft-skills training program, covering absenteeism, salary, promotion, employee suggestion activity and team-level quality outcomes.

Training was compulsory but rolled out in waves over about a year, so workers were treated at different times. The project exploits this staggered timing with an event-study design and a modern staggered-adoption estimator (Callaway & Sant'Anna), and compares it with naive two-way fixed effects. It also includes robustness checks, subgroup heterogeneity, text mining of suggestion data, and a cell-level analysis of productivity spillovers.

The repo covers the full workflow: merging data at three granularities (monthly worker panel, event-level text, daily team-level quality), building treatment timing, estimation, and tested, reproducible code.

Data & ethics: This project is inspired by real applied research on a corporate training program. Due to confidentiality obligations, no real company or individual-level data is used. All data is synthetic, generated by generate_synthetic_data.py to mimic the structure and treatment-timing patterns of the original setting. Estimates here describe the synthetic data and should not be read as findings about any real organization.
